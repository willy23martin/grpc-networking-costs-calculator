🧩 Microservices Patterns & Tactics
Distributed transaction across multiple microservices — multiplies networking costs.
How SAGA affects gRPC traffic

Your base RPS represents logical business transactions. Each SAGA instance fans out into N independent gRPC calls — one per step. The multiplier is:

effective gRPC calls/sec = base RPS × total steps per SAGA instance

Example: 1,000 RPS × 3 steps = 3,000 gRPC calls/sec. The steps replace the single call; they do not add to it.

If SAGA steps exit your VPC (third-party APIs, partner services, cross-region calls), AWS charges internet egress ($0.09+/GB). If all steps stay within the same VPC, intra-service traffic costs $0.00 (same-AZ) or $0.01/GB (cross-AZ) — effectively free for most workloads. Check this box only if any step exits the VPC.

🔒 Security Tactics
How security tactics affect TCO

Security impacts costs in two dimensions — payload size (byte overhead per message) and request count (handshake or token-acquisition calls). The formula:

effective RPS = tactics-adjusted RPS + handshake msgs/s + token acq/s + introspection/s
effective message size = proto size + TLS overhead + JWT header overhead

Ranges per RFC 8446 (TLS 1.3), RFC 7519 (JWT), RFC 7523, RFC 9101, RFC 6749.
